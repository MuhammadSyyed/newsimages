Subject: Progress Update - NewsImages MediaEval 2026 Task

Dear Sir,

I am writing to share a brief update on my NewsImages MediaEval 2026 work.

My task is to recommend the most fitting image for a given news article title/text using a retrieval-focused pipeline (with experimentation toward integrated retrieval + generation).

Dataset status:
- Training set: `newsimages_train_26_v1.1` with 8,500 articles (`news_articles.csv`) and 8,500 linked images (`news_images`).
- Test set: `newsimages_test_and_evaluation_26_v1.0/news_articles_test.csv` with 800 articles (used as text-only target set for final run generation/recommendation).
- Evaluation set: `news_articles_evaluation.csv` with 14,380 entries, plus `news_images_evaluation`; combined file `news_articles_combined.csv` has 15,180 rows.
- Generated evaluation file: `dataset/eval_dataset.json` contains 100 query titles, each with top-10 retrieved candidate images (created from my CLIP ViT-B/16 baseline).

Notebook/work summary (one-line each):
- `run_1_baseline_vit_b_32_clip.ipynb`: Baseline CLIP ViT-B/32 retrieval pipeline and initial ranking experiments.
- `run_2_baseline_vit_b_16_clip.ipynb`: Stronger CLIP ViT-B/16 baseline used to build ranked candidates for evaluation.
- `run_3_finetune_clip.ipynb`: Evaluation of retrieval after fine-tuning CLIP-oriented components.
- `run_4_integrated_pipeline.ipynb`: Integrated workflow combining retrieval and LLM-assisted processing in one pipeline.
- `run_5_baseline_vit16clip_siglip.ipynb`: Comparative baseline experiments between CLIP ViT-B/16 and SigLIP-style setup.
- `fine_tuning_clip.ipynb`: Focused CLIP fine-tuning/training notebook and model artifact saving.
- `LLM_Diffusion_Pipeline.ipynb`: Early prototype for text-to-image generation pipeline with LLM + diffusion tools.

Current deployed labeling work:
- The generated `eval_dataset.json` is already connected to my Streamlit labeling app (`app.py`).
- Candidate images are served via uploaded S3 links, and annotators are actively assigning relevance labels (0/1/2) per candidate image.

In short, I am approaching the task in stages: establish strong CLIP retrieval baselines, improve with fine-tuning and model comparisons, then integrate this into an end-to-end evaluation workflow with deployed human labeling for quality validation.
