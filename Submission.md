# NewsImages 2026 Submission Steps

Follow these steps in order.

## 1) Confirm registration

- Make sure your team is registered for NewsImages 2026.
- Use your official registered `group_name` in all submission files and folders.

## 2) Prepare your run outputs

- For each article in the provided dataset, generate **exactly one** recommended image per run.
- You can submit multiple runs (approaches), but each run must be meaningfully different.
- Inside a run, all images must be unique (no repeated image use).
- Do not use baseline/original news images for final run submissions.

## 3) Format each image correctly

- File type: `.png`
- Size: `460x260` pixels (landscape)
- Applies to both retrieved and generated images.
- Avoid stretching images; rescale or crop instead.

## 4) Use the required naming structure

- ZIP filename: `[group_name]_Submission.zip`
- Inside ZIP, create one folder per run:
  - `[group_name]_[approach_name]`
- Inside each run folder, name each image as:
  - `[article_id]_[group_name]_[approach_name].png`

Example:
- `MyTeam_Submission.zip`
- `MyTeam_CLIPRun/117_MyTeam_CLIPRun.png`

## 5) Prepare reproducible workflow/code

- Keep your workflow code/notebooks/scripts ready and documented.
- Use only open-source/open-weight models and share any additional dataset used.
- You must submit workflow details with your run submission.

## 6) Submit runs by email

Send an email to the address that sent you the dataset link. Include:

1. Your group name  
2. A download link to your run ZIP file  
3. Links to your workflow code/documentation (for example, GitHub repo)

## 7) Participate in online evaluation (mandatory)

- Dates: **May 7-14**
- Your team must rate other teams' image recommendations during the online event.
- Participation is required for valid challenge participation.

## 8) Submit Working Notes Paper

- Deadline: **May 31** (EasyChair)
- Include your method, workflow details, and results from online evaluation feedback.
- Be available for review and camera-ready updates.

---

## Important things to remember

- Registration is mandatory.
- Runs due: **May 1 (AoE)**.
- Working Notes Paper is mandatory for challenge submission.
- Your paper must describe the workflows used for submitted runs.
- Review participation is expected on EasyChair.
- Camera-ready deadline: **June 14 (AoE)**.
- Workshop dates: **June 15-16** (in-person or online attendance required).
